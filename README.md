# FreeBuff — Animation-first food rescue

This is a Vite + React landing-page prototype built around the FreeBuff concept.

## Included
- GSAP + ScrollTrigger cinematic entrance and scroll choreography
- Lenis smooth scrolling
- Custom cursor
- Floating food objects and glass/orb visuals
- Waste → Rescue storytelling
- Countdown section
- Animated food marketplace
- Horizontal food category movement
- Impact counters
- Rescue journey panels
- Restaurant/business section
- Responsive mobile layout

## Run

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Notes
- Food photos are remote Unsplash images in the demo.
- Live map and rescue radar are intentionally excluded.
- Replace the demo photos with your own assets later.
